## Инженерные правила

1. Не считать действие выполненным только по намерению или сообщению модели.
2. После записи изменения перечитать изменённый файл и проверить SHA/коммит.
3. После изменения поведения запускать соответствующую проверку.
4. Ошибки инструментов должны возвращаться агенту с диагностикой, достаточной для исправления.
5. Не дублировать уже существующие инструменты — сначала проверять текущую архитектуру.
6. При каждом существенном изменении обновлять этот файл.
