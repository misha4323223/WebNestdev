# WebNestDev — план аккаунтов и подготовки к production

## Цель
Сейчас WebNestDev должен позволять реальному пользователю пройти тот же основной сценарий, который будет на production: регистрация → вход → сессия → работа с проектом → GitHub → выход/повторный вход. На локальной машине данные хранятся в .webnestdev, без зависимости от Yandex Cloud.

- [x] Хеширование пароля через Node scrypt; пароль не хранится в открытом виде

- [x] API /api/auth/register, /login, /logout, /me

## Важное правило
Не делаем «фальшивую» авторизацию только на фронтенде. Локальная версия должна реально проверять пароль и сессию. При переходе на Yandex Cloud меняется инфраструктурный слой хранения/секретов, а пользовательский сценарий остаётся тем же.
