# DNS Setup — reg.ru (для WebNestDev, nestdev.ru)

**Когда**: после того, как на ВМ поднят Caddy (или OpenResty) и он слушает `:80` и `:443`.
**Цель**: панель `https://nestdev.ru` + превью `https://<uuid>.preview.nestdev.ru`.
**IP ВМ**: `178.236.27.102` (проверяй через `curl -s ifconfig.me` на ВМ, если менялся).

## Кабинет reg.ru (шаг за шагом)

### 1. Открой карточку домена
- Вкладка ЛК reg.ru → `Домены` → найди `nestdev.ru` → ссылка вида `/user/account/card/{id}`.
- Внутри → `DNS-серверы и управление зоной` (URL: `/user/account/card/{id}/nss/`).
- В блоке **Ресурсные записи** сейчас видно:
  ```
  A @   → 95.163.244.138
  A www → 95.163.244.138
  ```

### 2. Заменить A-записи (панель)

**Клик по строке `A @`**:
- Тип: `A`
- Имя: `@`
- Значение: `178.236.27.102`
- Сохранить

**Клик по строке `A www`**:
- Тип: `A`
- Имя: `www`
- Значение: `178.236.27.102`
- Сохранить

### 3. Добавить wildcard для превью

Клик по кнопке **«Добавить запись»**:
- Тип: `A`
- Имя: `*.preview` (это `*.preview.nestdev.ru`)
- Значение: `178.236.27.102`
- Сохранить

> ⚠️ На reg.ru `*.preview` — это **wildcard** для всех `<uuid>.preview.nestdev.ru`.

### 4. (опционально) CNAME для `www` → `nestdev.ru`

Если хочешь `www.nestdev.ru` вести на `nestdev.ru`, можно вместо A-записи `www` поставить:
- Тип: `CNAME`
- Имя: `www`
- Значение: `nestdev.ru`

### 5. Дождаться распространения

- TTL: 300–3600 сек (обычно 1–10 мин).
- Проверка:
  ```bash
  dig +short nestdev.ru A
  dig +short www.nestdev.ru A
  dig +short test.preview.nestdev.ru A   # должно ответить 178.236.27.102
  ```

## Что дальше (на ВМ)

1. Caddy (или OpenResty) должен быть на `:80` и `:443`, и слушать `0.0.0.0`.
2. В Caddyfile: `site { nestdev.ru, www.nestdev.ru } → reverse_proxy localhost:8787` (или твой port).
3. Для превью: `site { *.preview.nestdev.ru } → reverse_proxy localhost:8787` (один и тот же upsteam, а сервер сам решает, какой проект дать по `Host`).
4. TLS: Let's Encrypt (HTTP-01) — или Wildcard через DNS-01 (нужен API reg.ru / DNS-модуль Caddy / certbot).

## Ограничения / грабли

- Reg.ru сейчас показывает баннер про **идентификацию администратора через Госуслуги** (с 01.09.2026). Это может блокировать **массовые операции**, но обычно **карточка DNS и добавление записей** работают. Если нет — пройди идентификацию вручную.
- Kнопка «Добавить запись» открывается drawer справа. Иногда drawer перекрывает клик по другой кнопке — `Escape` или `browserOverlays { dismiss: true }` закрывает.
- Wildcard `*.preview` — одна запись. Не надо делать A-записи на каждый UUID вручную.
